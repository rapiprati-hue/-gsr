# oriori_gsr v2 — 운영자 대본 진행형 GSR 부스

노트북(운영자) + 태블릿(참가자) + Pico(GSR) 로 돌아가는 로컬 앱입니다. **운영자가 화면의 대본을 읽으며 진행**하고, 참가자는 태블릿에서 동의·응답·결과 평가만 합니다. 계산은 코드가, 문장은 규칙 또는 Claude 가 씁니다.

> `pico/main.py` 만 Pico 에 올립니다. `app.py` 는 노트북에서 실행합니다.

## 1. 지금 바로 (5개)
1. 폴더를 바탕화면에 두고 Python 3.11+ 설치 (Windows: *Add Python to PATH* 체크).
2. Windows `start_windows.bat` 더블클릭 / macOS 터미널에서 `bash start_mac.sh`. 첫 실행은 인터넷으로 라이브러리 설치. 창 닫지 말기.
3. 브라우저에 `http://127.0.0.1:8765` 가 열립니다 (안 열리면 직접 입력).
4. **＋ 새 검사 시작 → 사회 코스 → 세션 만들기 → '이 기기에서 태블릿 화면 열기' → 동의 → 진행 화면으로 → 측정 시작 → Enter / Space / 1~5 키로 끝까지 → 측정 완료 → 결과 → 영수증 열기 → 인쇄/PDF → 데이터 메뉴에서 CSV.**
5. 여기까지 되면 소프트웨어 끝. 그 다음이 하드웨어(아래 3장). 데모 데이터는 절대 분석에 쓰지 않습니다.

## 2. 코스 (가격은 `config.json` 의 `prices`)
| 코스 | 내용 | 시간 |
|---|---|---|
| 기본 · 나의 결 | 기준선 60초 → Big5 20문항(Mini-IPIP, 운영자가 읽음) → 회복 → 디지털 카드 | 약 5분 |
| 사회 · 타인 앞의 나 | 기본 + **실제 눈맞춤 4회(직접/회피)** + **질문 3개(중립/자기/사회평가)** 의 뜸·EDA → 영수증 | 약 8분 |
| 심층 · 결핍과 의미 | 사회 + **인터뷰 3문항(결핍/충만/의미) 메모** → **Claude 가 '오늘의 나의 캐릭터' 서사** → 참가자 정확도 평가 → 전체 영수증 | 약 11분 |

MBTI 4글자는 결과 하단의 참고 표기일 뿐입니다(공식 MBTI 아님). 헤드라인은 심층 코스의 캐릭터 서사, 그다음이 Big5 와 몸의 반응입니다.

## 3. 하드웨어 — 순서대로 (운영 화면 **준비 가이드** 메뉴와 동일)
1. **배선 (전원 뺀 상태)**: GSR SIG → GP26(물리 31), GND → GND(38), VCC → 모듈 사양대로(3.3V 지원 시 3V3 OUT 36). 버튼(선택) S → GP14(19). **온습도(DHT11)·사운드는 제외**. 신호가 3.3V 를 넘는 모듈은 직결 금지.
2. **Thonny → Pico**: BOOTSEL 누른 채 USB → MicroPython 펌웨어 → Thonny 에서 `pico/main.py` 를 Pico 에 `main.py` 로 저장 → 셸에 `{"seq":…,"adc":…}` 가 흐르면 OK → **Thonny 완전 종료**.
3. **앱 하드웨어 모드**: 운영 화면 설정에서 포트 선택(COM3 / /dev/tty.usbmodem…) → `config.json` 의 `"mode": "hardware"` → 앱 재시작 → 대시보드 그래프가 실제로 움직이고, USB 를 뽑으면 '끊김' 이 되는지 확인.
4. **극성 확인 (중요)**: 밴드를 본인 손가락에 끼우고 **깊게 숨 들이쉬고 참기** → 몇 초 뒤 그래프가 **올라가면** 설정의 '각성 시 ADC 상승' 켜기, **내려가면** 끄기. 모듈마다 방향이 반대라 이걸 안 하면 반응 부호가 뒤집힙니다.
5. **핫스팟**: 노트북 개인 핫스팟 → 태블릿 연결 → 대시보드 상단 태블릿 주소(IP) 로 열림 확인. 학교 와이파이는 기기 간 통신을 막는 경우가 많음. `localhost` 는 태블릿에서 안 됨.
6. **Claude**: `.env.example` → `.env` 복사, `ANTHROPIC_API_KEY=` 입력, 재시작 → 사이드바 'Claude ON'. 키가 없어도 규칙 문장으로 전부 진행. 심층 코스 + 참가자 선택 동의 세션만 전송.
7. **프린터**: 제조사 드라이버 → OS 테스트 페이지 → 결과 화면 **영수증 열기** → 브라우저 인쇄(여백 최소, 머리글/바닥글 끄기, 감열지 너비 선택). 자동 커터가 꼭 필요하면 `config.json` 의 `printer` 를 `win32`/`usb`/`network` 로 (README 끝 참고). Zadig 로 드라이버 함부로 바꾸지 말 것.
8. **파일럿 2회** 후 학교 승인·보호자 동의 확인 → `config.json` 의 `schoolApprovalConfirmed: true` (하드웨어 모드에서 시작 조건).

## 4. 진행 화면(대본) 사용법
- 왼쪽 큰 글씨가 **읽을 말**, 아래 상자가 **운영 팁**. 오른쪽은 실시간 신호·태블릿 상태·단계 목록.
- `Enter` 다음 단계 · `Space` 질문 끝 → 답변 시작 → 답변 끝 · `1`~`5` 참가자가 말로 답한 Big5 응답 입력(태블릿에서 눌러도 자동 반영).
- 눈맞춤 단계는 '띵' 소리와 함께 5초 자동 진행(직접: 참가자 눈을 본다 / 회피: 노트북 화면을 본다). 순서는 세션마다 ABBA 로 바뀜.
- 인터뷰 메모는 참가자 표현 그대로 키워드만. 이름·학교·연락처 금지. 메모는 Claude 프롬프트에 그대로 들어갑니다.
- 화면을 새로고침해도 서버가 단계를 기억합니다. 중단은 양쪽 어디서나 가능하며 원시 데이터는 보존됩니다.

## 5. 데이터 (엑셀로 바로 열림)
운영 화면 **데이터** 메뉴: 요약 CSV(세션 1행) · **이벤트별 반응 CSV(자극 1행, 논문용)** · 원시 CSV · 이벤트 CSV · 전체 JSON. CSV 는 UTF-8 BOM 이라 엑셀에서 더블클릭하면 한글 그대로 열립니다.
`python analyze.py` 는 data/ 에서 전부 다시 계산해 `analysis_sessions.csv`, `analysis_responses.csv` 와 범주별 z 요약을 출력합니다. 변수 정의는 `DATA_DICTIONARY.md`, 설계·가설·한계는 `PROTOCOL.md`.

## 6. Claude 는 무엇을 받고 무엇을 하나 (심층 코스 · 선택 동의 세션만)
**모델: Claude Sonnet 5 (`claude-sonnet-5`), thinking 끔.** Sonnet 5 는 기본으로 adaptive thinking 이 켜져 있어 코드가 매 요청에 `thinking: {type: "disabled"}` 를 보냅니다(부스용 5문장에 사고 과정은 필요 없고, 속도·비용·재현성이 우선). Sonnet 5 는 `temperature/top_p/top_k` 를 바꾸면 400 오류이므로 샘플링 파라미터는 아예 보내지 않습니다. 모델 ID 가 계정에서 404 면 `/v1/models` 에서 최신 sonnet 을 찾아 자동 대체하고(세션 `report.notes` 에 기록), thinking 필드를 거부하는 모델이면 필드 없이 재시도합니다.

받는 것: Big5 0–100, 상황별 반응을 **말로 바꾼 것**(뚜렷하게 올라감/큰 변화 없음…), 질문별 뜸(거의 바로/한참 뜸을 들인 뒤…), 운영자 메모. 안 보내는 것: 이름, 음성, 원시 신호, 문항별 원응답.

하는 일 5가지 — 모두 JSON 한 번으로 돌아옵니다:
1. **캐릭터 이름 + '오늘의 나'** 3–4문장(메모의 표현을 그대로 인용, 몸의 반응과 뜸을 엮음).
2. **결핍과 의미** 3–4문장 — 처방·조언 금지, 되비추기만.
3. **집에 가져갈 질문** 한 문장 — 답을 주지 않고 질문을 남깁니다(영수증에도 인쇄).
4. **코드북 코딩** — 메모를 `결핍 영역(관계/인정/시간/휴식/돈/자율/능력/안전/없음)`, `충만 맥락(관계/창작/성취/몰입/자연/휴식/기여/없음)`, `의미 원천(관계/성장/기여/창작/신념/즐거움/없음)`, `정서 톤(따뜻함/중립/무거움)` 으로 분류 → 세션 CSV 열(`code_lack, code_filled, code_meaning, affect_tone`). 주관적 인터뷰가 **분석 가능한 변수**로 남는 부분입니다(운영자 검토 후 한 명이 재코딩하면 일치도 계산 가능).
5. **안전 플래그** — 자해·위기 신호가 의심되면 `safetyFlag` 를 세웁니다. 그러면 문장은 담백하게 나오고 **태블릿에는 보이지 않은 채 보류**됩니다. 운영자가 결과 화면의 빨간 배너에서 읽고(필요하면 `문장 수정`) `확인했어요 · 태블릿에 공개` 를 눌러야 참가자에게 보입니다. 이때는 문장보다 사람이 우선입니다 — 담당·상담 선생님께 연결하세요.

검증: 5개 문장 필드 필수, 숫자·%·진단·유형 확정 문장은 코드가 거부하고 규칙 문장으로 대체(`source: rules-fallback`, 사유 저장). 운영자는 어떤 결과든 `문장 수정` 으로 고칠 수 있고 원문은 `report.original` 에 보존됩니다. 모델명·프롬프트 버전(`deep-character-v2`)·thinking 상태·토큰 사용량이 세션에 저장됩니다. 모델은 `.env` 의 `ANTHROPIC_MODEL` 로 변경.

## 7. 정확성·윤리 (요약)
Mini-IPIP 원문은 퍼블릭 도메인(IPIP), 한국어 번역은 비공식이라 타당화되지 않았습니다. 0–100 은 응답 환산값이지 백분위가 아닙니다. 4글자는 공식 MBTI 가 아닙니다. GSR 은 비특이적 각성 지표이며 감정·거짓말·애착·미주신경을 판독하지 않습니다. 눈맞춤은 살아 있는 사회적 자극에 대한 EDA 반응 패러다임(Hietanen et al., 2008)을 부스용으로 단순화한 것입니다. 미성년자 연구 활용은 별도 승인·보호자 동의가 필요하며 이 배포에서는 연구 동의가 비활성화되어 있습니다. 데이터는 30일 후 자동 삭제, 원시 데이터 공개 금지, `.env` 와 `data/` 는 GitHub 에 올리지 않습니다.

## 8. 파일
`app.py` 서버/API · `engine.py` 대본·채점·반응 계산·Claude·영수증 · `static/` 빌드 없는 순수 JS 화면 · `pico/main.py` 펌웨어 · `analyze.py` 재분석 · `test_engine.py` 자동 테스트(`python -m unittest test_engine -v`) · `config.json` 설정 · `.env` 키.

### ESC/POS 직접 인쇄 설정 (`config.json`)
`printer`: `browser`(기본) / `win32`(`printerName` 에 Windows 프린터 이름) / `usb`(`printerVid`, `printerPid`, 엔드포인트) / `network`(`printerHost`, 9100). `paperWidth` 58 → 384px, 80 → 576px. 한글은 이미지로 렌더링(폰트: `assets/NanumGothic-Regular.ttf` 또는 시스템 폰트 자동 탐색). `autoCut` 미지원 프린터는 false.

### 문제 해결
`Address already in use` → 이전 창 종료 또는 `config.json` 의 `port` 변경 · 센서 '끊김' → Thonny 켜져 있음/포트 오타/충전 전용 케이블 · 태블릿 안 열림 → IP 주소 사용, 같은 핫스팟, 방화벽에서 Python 허용 · Claude 실패 → 결과 화면에 사유 표시, 규칙 문장으로 계속 · 결과 화면에 빨간 배너 → 안전 보류, 읽고 `태블릿에 공개` 를 눌러야 참가자에게 보임.

### 미리보기 전용 옵션
`ORIORI_ALLOW_REMOTE_OPERATOR=1` 은 운영 API 의 localhost 제한을 끕니다(원격 미리보기/테스트용). **현장에서는 절대 켜지 마세요.**
