# oriori_gsr / 프로토콜 v2 — `oriori-live-social-v2`

## 한 줄 요약
**살아 있는 사람(운영자) 앞에서** 자기보고 · 눈맞춤 · 자기개방 질문을 수행할 때의 피부전도(EDA/GSR) 반응과 응답 지연을 기록하고, 심층 코스에서는 그 기록과 참가자의 말을 Claude 가 한 사람만의 서사로 되돌려 준 뒤 **참가자가 그 서사의 정확도를 평가**한다.

운영자는 대본을 읽으며 진행한다(문항 화면을 참가자 혼자 푸는 검사가 아님). 계산은 코드가, 문장은 규칙 또는 Claude 가, 판단은 참가자가 한다.

## 왜 이 설계인가 (사회신경과학 연결)
| 과제 | 근거가 되는 패러다임 | 이 부스에서의 측정 |
|---|---|---|
| 실제 눈맞춤 (직접 vs 회피 시선, ABBA 4회) | 살아 있는 상대의 직접 시선이 사진보다 큰 SCR 을 유발 (Hietanen et al., 2008, *Neuropsychologia*) | 시선 시작 후 1–6 초 창 최대 편차 z, 직접 − 회피 대비 |
| 질문 유형 (중립 / 자기 참조 / 사회적 평가) | 자기 참조 처리·사회적 평가 위협은 각성과 처리 부담을 높임 (Dickerson & Kemeny, 2004 의 사회평가 위협; 자기 참조 효과) | '질문 끝'→'답변 시작' 지연(뜸), 질문 끝 후 EDA z |
| Big5 자기보고 중 EDA | 문항 응답 중 각성 기록(탐색) | 문항별 z, 응답 지연 |
| 결핍·충만·의미 인터뷰 (심층) | 기본심리욕구 좌절/충족, 삶의 의미 — 여기서는 **측정 척도가 아니라 자기개방 자극** | 지연, EDA z, 운영자 메모(참가자 표현) |
| Claude 서사 + 정확도 평가 | 개인화 피드백 수용도(바넘 효과 연구 전통)의 확장: 규칙 문장 vs 개인화 서사 | 참가자 정확도 1–5, 와닿은 문장 선택 |

## 흐름 (모두 운영자 대본 순서)
1. 태블릿 동의: 필수(체험·저장) / 선택(Claude API 전송, 심층만 적용). 연구 동의는 항상 비활성.
2. `측정 시작` 과 동시에 raw.csv 기록 시작 (20 Hz). 인사 → 센서 착용(신호 확인) → **기준선 60 초**(고정점).
3. **Big5 20 문항** (Mini-IPIP, 운영자가 읽고 참가자가 태블릿 5점 버튼 또는 구두 응답 → 운영자 1–5 키). 문항 시작 = 단계 시작 시각.
4. (사회·심층) **눈맞춤 4회**: 5 초 시선 + 10 초 휴식. 순서는 세션 번호 홀짝으로 ABBA 반균형화. 시작/끝 '띵' 소리.
5. (사회·심층) **질문 3개** 고정 순서: 중립 → 자기 → 사회평가. 운영자 Space 3회: 질문 끝 / 답변 시작 / 답변 끝.
6. (심층) **인터뷰 3개**: 결핍 → 충만 → 의미. Space 3회 + 키워드 메모(이름·학교 금지).
7. **회복 30 초** → `측정 완료` → 계산 → (심층 + 동의 + 키) Claude 서사 → 태블릿 결과 → **정확도 평가**.

데모 모드 타이머: 기준선 6 초, 휴식 4 초, 회복 5 초.

## 시계
raw.csv 의 `t` 와 events.csv 의 `hostElapsedMs` 는 **같은 서버 monotonic 시계**(측정 시작 = 0). 태블릿 응답·운영자 표시는 서버 수신 시각으로 기록되므로 핫스팟 왕복 지연(수십 ms)과 운영자 반응 지연이 포함된다. 따라서 **절대값이 아니라 참가자 내 조건 간 비교**에 쓴다.

## 계산 (engine.compute_features)
- 기준선: `baseline` 단계 시작부터 60 초(데모 6 초)의 ADC 평균과 SD.
- 이벤트 반응: `amplitude = max(ADC[onset+1s, onset+6s]) − mean(ADC[onset−1s, onset])` (극성이 반대인 모듈이면 min 과 부호 반전). `z = amplitude / baseline SD`.
- onset: 눈맞춤·문항 = 단계 시작, 질문·인터뷰 = '질문 끝' 표시(없으면 단계 시작).
- 지연: `answer_start − asked_end` (ms). Big5 는 `응답 − 문항 시작`(읽는 시간 포함, 참고용).
- 범주 평균 z, 대비(직접−회피, 자기−중립, 사회−중립), 질문 지연 중앙값.
- Big5: 역채점 후 요인당 평균 → 0–100 환산. 요인당 2문항 이상 있어야 산출. 4글자는 E/O/A/C 의 50 기준 이분화 **참고 표기**이며 공식 MBTI 가 아니다.

## 사전 가설 (데이터 보기 전에 날짜와 함께 고정할 것)
H1 직접 시선 z > 회피 시선 z (참가자 내). H2 자기·사회평가 질문 z > 중립 질문 z. H3 사회평가 질문 지연 > 중립 질문 지연. H4 N(정서 민감성) 과 사회평가 질문 z 의 양의 상관(탐색). H5 Claude 서사의 정확도 평가 > 규칙 문장 평가(코스가 다르므로 혼입 있음 — 탐색).
제외 기준(사전): 품질 < 90 %, 기준선 SD = 0 또는 레일 근접, 관측 Hz < 15, 단계 순서 역행 이동, 중단 세션.

## 한계 (그대로 보고할 것)
보정 전 ADC(μS 아님) · 검증되지 않은 SCR 알고리즘(단순 창 최대) · 운영자 1인 · 축제 편의표본 · 짧은 기준선 · 문항 간 반응 중첩 · 운영자 시선 조건의 표정/자세 통제 부족 · Mini-IPIP 한국어 번역 비공식 · Claude 출력은 확률적(프롬프트 버전·모델명 저장) · 태블릿·운영자 반응 지연 포함. 감정·거짓말·애착·미주신경 판독 아님. 연구 활용은 별도 승인 전까지 비활성.
