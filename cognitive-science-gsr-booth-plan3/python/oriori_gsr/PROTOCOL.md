# oriori_gsr / exploratory-v1

## 목적과 범위
비진단적 학교 축제 인지과학 체험. 확정 성격, MBTI 검사, 감정/거짓말 판독, 미주신경 평가, 검증된 인터로셉션 평가가 아님. 짧은 스피치는 TSST가 아님. 연구 활용 비활성화.

## 흐름
운영자: 학교 운영 승인과 필요한 보호자 동의 → 가격/과제/중단/보관 안내 → 코스 선택 → 무작위 세션 ID → 태블릿 동의(외부 AI 선택 동의 분리) → 자체 문항 10개 → 센서 착용 확인 → 기준선 → 과제 → 규칙 설명 또는 동의 기반 LLM 설명 → 디지털 결과 → 선택 영수증 → 비공개 저장.

## 단계와 시간
| 단계 | 실제 | 데모 | 코스 |
|---|---:|---:|---|
| baseline | 60초 | 6초 | 전부 |
| reaction | 30초, 5회 | 10초, 5회 | 전부 |
| social | 36초, 3문장 | 6초 | relation/full |
| awareness | 30초 | 4초 | relation/full |
| anticipation | 20초 | 4초 | full |
| speech | 20초, 거절 가능 | 5초 | full |
| recovery | 30초 | 5초 | full |

화면 반응 목표는 각 trial 내 표시되며 onset 및 응답을 브라우저 performance 시계로 기록한다. 교육용 예측 가능한 자극 순서이므로 정식 인지실험의 무작위화·반균형화·연습 시행을 대신하지 않는다. GSR 기준선부터 마지막 회복까지 원시 신호를 중단 없이 기록한다. 지시문 변경은 stage 이벤트로 남긴다. 발화 거절은 speech_skipped로 저장하며 쉬는 구간으로 진행한다. 언제든 중단 가능.

사회 문장: (1) 가까운 사람이 나를 칭찬해 주었던 순간 (2) 새로운 친구와 처음 인사를 나누던 순간 (3) 좋아하는 사람과 즐겁게 이야기하던 순간. 단어연상/트라우마 회상/고압 면접은 실시하지 않음.

## 자체 탐색 설문 — 1 전혀 아니다 ~ 5 매우 그렇다
1. 새로운 아이디어를 떠올리는 일이 즐겁다. (O+)
2. 시작한 일은 계획대로 마무리하려고 한다. (C+)
3. 다른 사람과 함께 있을 때 활력이 생긴다. (E+)
4. 다른 사람의 입장을 이해하려고 노력한다. (A+)
5. 작은 일에도 걱정이 오래 이어지는 편이다. (N+)
6. 익숙한 방식에서 벗어나는 일이 불편하다. (O−)
7. 할 일을 정리하기보다 그때그때 처리한다. (C−)
8. 모임에서 이야기하기보다 조용히 있는 편이다. (E−)
9. 의견이 다르면 상대의 기분보다 내 주장을 앞세운다. (A−)
10. 예상하지 못한 일이 생겨도 차분함을 유지한다. (N−)

각 요인 = `round(((긍정문항 + 6 - 역방향문항) / 2 - 1) × 25)`.
4글자 참고 표현: E≥50 → E, 아니면 I; O≥50 → N, 아니면 S; A≥50 → F, 아니면 T; C≥50 → J, 아니면 P. **임의 체험용 이분화이며 공식 MBTI 변환이 아니다.** 경계값을 유형의 실재/확률/확신으로 해석하지 않는다. N(정서 민감성)은 4글자 유형에 포함하지 않는다.

## 인쇄
레이아웃은 고정 템플릿. 로고/코스/ID/Big5 환산점수/4글자 참고값/ADC와 환경/설명/한계/QR. LLM은 설명 슬롯만 채우며 숫자를 계산하거나 감정·기질을 확정하지 않음. BASIC 디지털, RELATION 간략 영수증, FULL 추가 지표 포함. API 실패 시 규칙 설명.

## 파일럿 확인
3명 이상에게 동의 문구·중단·삭제를 설명하고, 잘 이해되는지 확인. 실제 소요시간·장비 간 시각 오차·포화/결측·DHT 실패·Wi-Fi 끊김·프린터 장애를 기록. 먼저 수집한 파일럿을 사전등록된 연구 데이터라고 바꾸어 부르지 않음.

이 문서는 연구 윤리 심의나 연구계획서의 대체물이 아니다. 학술 활용 전 독립적으로 검증된 척도/장비/승인/분석계획을 마련한다.
